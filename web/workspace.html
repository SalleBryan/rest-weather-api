Connect a compatible Weather Board API to keep observations, find saved locations, and explore their history. For worldwide forecasts, head to Explore weather.

Use your WeatherApiUrl from SAM, or a local Weather Board API. No credentials in the URL. HTTPS is required except for localhost.

Nothing connects automatically, even when a URL is saved.

Keep requests intentional.

10 requests per minute and 100 per UTC day in this browser. Reads use pages of 20, with more loaded on request. No polling or automatic retries. Disconnect to stop new requests and cancel pending requests.

Connect only to an API you control or trust. It must implement this project’s routes and allow browser requests (CORS). This public learning API does not provide authentication. Browser limits can be reset or bypassed; your provider’s quotas and billing controls are still needed. AWS API Gateway’s existing 5 requests/second and burst of 5 are best-effort throttles, not a spending cap.
